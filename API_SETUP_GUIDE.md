## 1. 🧠 Free Google Gemini API Key (AI Therapist Engine)

Google Gemini provides a **100% Free Tier** with generous rate limits.

### Step-by-Step:
1. Go to **[Google AI Studio](https://aistudio.google.com/app/apikey)**.
2. Sign in with any Google account.
3. Click **Create API Key**.
4. Select or create a project, then copy your API Key (it starts with `AIzaSy...`).
5. Send your Gemini API Key here or paste it into your Haven settings.

# Haven - Personal Emotional Sanctuary & Wellness App 🌟

A deeply personal, warm, and comforting web application designed to provide emotional support, grounding, reflection, and quiet joy for someone navigating detachment, longing for connection, or heavy emotions.

## ✨ Features

- **🌌 Sky Lanterns of Release**: Express unspoken thoughts, feelings, or memories to loved ones or your inner self and release them into an interactive star-lit sky.
- **🌬️ Grounding Breathing Oasis**: Guided visual breathing exercises (4-7-8 Relax & 4-4-4 Box Breathing) with soothing visual expansion rings.
- **🎶 Web Audio Soundscapes**: Built-in dynamic procedural audio synthesizers for Gentle Rain, Cozy Campfire, Ocean Waves, Night Breeze, and Celestial Chimes (offline & zero dependencies).
- **🏺 Memory & Comfort Jar**: Interactive glass jar containing glowing notes of reassurance, affection, and personal reflections.
- **🤍 Virtual Hug & Tea Ritual**: Interactive heart bloom hug button and a mindful "Brew a Warm Cup of Tea" grounding mini-ritual.
- **📝 Safe Space Journal & Heart Log**: Daily feeling check-in with empathetic validating responses and a private local storage journal.
- **🎨 Dynamic Themes**: Twilight Night, Warm Sunset, Rose Gold, and Emerald Peace.

## 🚀 Getting Started

```bash
npm install
```

### Development
